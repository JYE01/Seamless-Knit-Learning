Brief Project Description
This is the project for making the comprehensive online learning platform for knitting and Shima Seki knitting machine.
The online learning platform should support beginners to learn the foundation of knitting and provide a guidance to Shima Seki knitting machine.
Client wanted the functionalities like module, quiz, and discussion boards.
Admin page was optional but was preferred by the client.
Admin page contains add/remove modules, add/remove quizzes, add/remove disccusions, and track the module & quiz progress.

*IMPORTANT!*
This program is based on react.js framework and firebase database.
